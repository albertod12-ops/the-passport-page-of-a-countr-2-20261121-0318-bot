The passport spread of the Republic of Marenna — a country that isn't
there. A lagoon republic of stilt towns on the Grey Lagoon, where the
only way in or out is the pole-ferry at slack water. The holder, Selma
Orren, is a licensed lagoon ferry pilot (lic. FP-118): her occupation,
the ferry pilot's endorsement, the lagoon toll stamp, the visa from
neighbouring Aldorne, and a paired entry/exit travel history all agree
with that, dated after the passport was issued on 14 MAR 2023 and
before it expires on 13 MAR 2033.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, Pillow) draws the whole 1024x1024 spread to
`/output/entry.png` — paper, guilloche, emblem, data page with an ICAO
machine-readable zone (check digits computed, not typed), endorsement,
visa, stamps, and a ferry-route map. The portrait is a photograph
generated for this entry, kept as `portrait.jpg`. No network, no
randomness: two runs produce the same bytes.
